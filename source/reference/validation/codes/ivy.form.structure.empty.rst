ivy.form.structure.empty
------------------------

**Message:** Structure has no child components

.. start: manual doc

**Description**

A Structure is a container for child components. With no children, it contains no controls or other form content and has no purpose in the form layout.

**How to fix**

Add the components that the Structure is intended to contain, or remove the empty Structure from the form. See the :ref:`Form Editor <form-editor>` guide for adding and organizing components.
