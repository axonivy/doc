ivy.xhtml.missing-composite-attribute-type
------------------------------------------

**Message:** Composite component attribute '${attribute}' has no type defined. Add either a type="..." or method-signature="..." definition so the validator knows the attribute's type. Without one, validation of usages is skipped and related errors may go undetected.
