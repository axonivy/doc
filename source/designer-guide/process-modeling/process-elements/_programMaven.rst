Maven dependency
~~~~~~~~~~~~~~~~~~~~

In order to supply a Program implementation, additional API is needed.
Add the following dependency to your project's :file:`pom.xml` to get it:

.. code-block:: xml

    <dependencies>
      <dependency>
        <groupId>com.axonivy.ivy.api.extension</groupId>
        <artifactId>ivy-process-extension-api</artifactId>
      </dependency>
    </dependencies>
