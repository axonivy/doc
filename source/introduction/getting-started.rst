Getting Started
***************

**Designer**

The Axon Ivy Designer is the development environment where you can model, design, 
and implement your business processes and applications. It provides tools for 
creating process diagrams, forms, and business logic, and allows you to test and debug your 
applications locally before deploying them to the Axon Ivy Engine.

To install a designer, follow the instructions in the :ref:`designer installation guide <designer-installation>`.

**Engine**

The Axon Ivy Engine is the runtime environment where your business processes and applications 
are executed. It handles process orchestration, task management, and integration with external 
systems. The Engine ensures that your applications run reliably and efficiently in a production environment.

To install an engine, follow the instructions in the :ref:`engine installation guide <engine-installation>`.
